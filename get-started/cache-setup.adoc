= NetApp Volume Caching einrichten
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Um Volume Caching zu nutzen, müssen Sie einige Schritte zur Einrichtung durchführen.

* Rezensionlink:../get-started/cache-prerequisites.html["Voraussetzungen"] um sicherzustellen, dass Ihre Umgebung bereit ist.
* Erstellen Sie einen Konsolenagenten.
* Systeme entwickeln, die Volume-Caching unterstützen.




[[create-a-console-agent-in-the-netapp-console]]
== Erstellen Sie einen Konsolenagenten in der NetApp Console

Der nächste Schritt besteht darin, einen Konsolenagenten in der NetApp Console zu erstellen.

Um einen Console-Agenten vor der Verwendung von Volume Caching zu erstellen, bietet die NetApp Console Dokumentation link:https://docs.netapp.com/us-en/console-setup-admin/concept-agents.html#what-a-console-agent-does["Konsolenagenten"^] entsprechende Informationen.



[[create-systems]]
== Systeme erstellen

Falls noch nicht geschehen, müssen Sie die Systeme für Quelle und Ziel erstellen.

* https://docs.netapp.com/us-en/cloud-manager-fsx-ontap/start/task-getting-started-fsx.html["Erstellen Sie ein Amazon FSx für ONTAP -System"^]
* https://docs.netapp.com/us-en/cloud-manager-cloud-volumes-ontap/task-deploying-otc-aws.html["Starten Sie Cloud Volumes ONTAP in AWS"^]
* https://docs.netapp.com/us-en/cloud-manager-cloud-volumes-ontap/task-deploying-otc-azure.html["Starten Sie Cloud Volumes ONTAP in Azure"^]
* https://docs.netapp.com/us-en/cloud-manager-cloud-volumes-ontap/task-deploying-gcp.html["Starten Sie Cloud Volumes ONTAP in GCP"^]
* https://docs.netapp.com/us-en/cloud-manager-cloud-volumes-ontap/task-adding-systems.html["Hinzufügen vorhandener Cloud Volumes ONTAP -Systeme"^]
* https://docs.netapp.com/us-en/cloud-manager-ontap-onprem/task-discovering-ontap.html["Entdecken Sie ONTAP Cluster"^]
