= Häufig gestellte Fragen zum Volumen-Caching
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Diese FAQ können hilfreich sein, wenn Sie nur schnell eine Antwort auf eine Frage suchen.

*Wie lautet die Volume Caching-URL?* Für die URL in einem Browser eingeben: https://console.netapp.com/["https://console.netapp.com/"^], um auf die NetApp Console zuzugreifen.

*Benötigen Sie eine Lizenz für die Nutzung von Volume Caching?* Eine NetApp -Lizenzdatei (NLF) ist nicht erforderlich.

*Wie aktiviert man Volume-Caching?* Für das Volume-Caching ist keine Aktivierung erforderlich. Die Option „Volume-Caching“ wird automatisch in der linken Navigationsleiste der NetApp Console angezeigt.
