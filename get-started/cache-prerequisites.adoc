= Voraussetzungen für NetApp Volume Caching
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Beginnen Sie, indem Sie die Bereitschaft Ihrer Betriebsumgebung, Anmeldung, Netzwerkzugriff und Ihres Webbrowsers überprüfen.

Um Volume Caching nutzen zu können, müssen Sie sicherstellen, dass Ihre Umgebung alle Anforderungen erfüllt.

* ONTAP 9.8 und höher
+
** Cluster Admin ONTAP Berechtigungen
** Intercluster-LIFs auf den Clustern


* In der NetApp Console:
+
** Die Einrichtung des Console Agent erfolgt in der NetApp Console. Alle Quell- und Zielcluster müssen denselben Console Agent verwenden. Informationen dazu enthalten link:https://docs.netapp.com/us-en/console-setup-admin/task-quick-start-standard-mode.html["Einstiegsarbeitsablauf für die NetApp Console"^] und link:https://docs.netapp.com/us-en/console-setup-admin/concept-agents.html["Erfahren Sie mehr über Konsolenagenten"^].
** Die Arbeitsumgebung sollte eingerichtet sein.
** Die Cluster sollten in der Zielarbeitsumgebung und in einem eingeschalteten oder herabgestuften Zustand hinzugefügt werden.
** Standardanforderungen für die NetApp Console . Siehe https://docs.netapp.com/us-en/cloud-manager-setup-admin/reference-checklist-cm.html["NetApp Console"^] .
