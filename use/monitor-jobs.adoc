= Überwachen Sie Volumen-Caching-Aufträge auf der Audit-Seite
:hardbreaks:
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Sie können alle Volume-Caching-Aufträge überwachen und deren Fortschritt über die NetApp Console -Audit-Seite ermitteln.

.Schritte
. Wählen Sie im NetApp Console *Administration* > *Audit*.
. Filtern Sie optional nach Zeit, Dienst, Aktion, Agent, Ressource, Benutzer oder Status.
. Erkunden Sie alle Caches und Vorgänge.
